# Zulian Social Media Marketing

Sito web professionale per **Zulian Social Media Marketing** — Agenzia di Social Media Marketing per Brand Ambiziosi.

## 🚀 Caratteristiche

- **Design premium dark** con animazioni fluide e micro-interazioni
- **GSAP animations** — Skew text reveal, parallax, fade, counter animations
- **Lenis smooth scroll** — Scrolling ultra-fluido
- **SplitType** — Text splitting per animazioni tipografiche avanzate
- **Responsive design** — Ottimizzato per desktop, tablet e mobile
- **Loader animato** — Counter da 0% a 100% con animazione premium
- **Navigation fullscreen** — Menu a schermo intero con animazioni staggered
- **Service cards** con tilt effect 3D al mouseover
- **Portfolio grid** con hover effects cinematici
- **Filling text** — Testo che si rivela progressivamente durante lo scroll

## 🛠️ Tecnologie

- HTML5
